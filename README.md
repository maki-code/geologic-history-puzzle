# 地史判読シミュレーション・パズル (Geologic History Puzzle)

## 概要
このアプリケーションは、地質学の基本法則である「地層累重の法則」と「交差切りの法則」を、ブラウザ上の操作を通して体感的に理解するための教育用論理パズルです。

## 対象
地学基礎を学ぶ中学生・高校生、および地球システム科学などの教養レベルの初学者。

## 本アプリの教育的意図と特徴
* **法則の視覚化**: 堆積、褶曲、断層、不整合（浸食）、マグマの貫入といった地質イベントを組み合わせることで、地質断面図がどのように変化するかをリアルタイムに確認できます。
* **等結果性の許容（採点ロジック）**: 現実の地史においては、異なるイベント順序が同一の地質構造を生み出すことがあります。そのため、本システムでは「イベントの順序文字列（ユーザーの操作手順）」の完全一致ではなく、「最終的な地質断面図のピクセル一致率」で正誤判定を行っています。これにより、科学的に妥当な別解を不当に弾くことなく正解として許容します。

## 遊び方・使い方
以下のURLからブラウザで直接アクセスして実行できます。
👉 **[ここにGitHub PagesのURLを記載する]**

1. 画面右側に表示される「目標の断面図」を確認します。
2. 画面下部のボタンから地質イベントを追加し、タイムラインを構築します。
3. タイムラインの「▲」「▼」ボタンでイベントの発生順序（相対年代）を入れ替えます。
4. 左側の「あなたの断面図」が目標と97%以上一致すればクリアです。

## 技術スタック
* HTML5 / CSS3
* JavaScript (Vanilla)
* 外部ライブラリ不使用、Canvas APIによる2D配列ベースのピクセル変形描画

## ローカルでの実行方法
1. 本リポジトリをクローン、またはZIPでダウンロードします。
2. `index.html` を任意のWebブラウザ（Chrome, Edge, Safari等）で開くだけで動作します。ローカルサーバーは不要です。
